Servicio objetivo del runtime conversacional soberano.

Responsabilidades:

- planner conversacional
- policy gate
- ejecucion de tools
- card renderer
- synthesizer
- answer guardrail
- persistencia del `AnswerEnvelope`

No incluye:

- scoring
- compatibilidad legacy de borde
