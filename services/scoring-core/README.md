# scoring-core

Servicio objetivo para scoring asincrono, separado del runtime conversacional (`ai-runtime`).

Responsabilidades:

- jobs de scoring
- worker de scoring
- scorecards
- prompts y modelos de scoring existentes

No incluye:

- decision conversacional
- planner
- synthesizer de chat
